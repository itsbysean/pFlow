# Link review

For each new edge, independently trace invocation → bound messaging system and scoped destination → routing/type constraints → enabled registration → receiving handler. Endpoint/source existence alone is not transfer evidence. Check both positive and negative candidates, local waiting modes, preserved external boundaries, full source-role coverage and stable graph ownership.

Reject links based on names, unused config, independent environment placeholders or assumed broadcast. Verify group/competing labels describe eligible alternatives, not guaranteed delivery. Preserve upstream branch restrictions. Review event chains as a finite graph; an existing consumer/publication must not be copied each time a cycle returns to it.

Run shared schema/semantic validation and existing document-reference validation. Separately compare the actual matching evidence, since validators cannot prove it. Use controlled authored fixtures for registration/caller/route behavior; do not execute an unknown repository or live broker. Blind evaluations must exclude intended oracles and tests. Include changed broker/filter/configuration cases to detect copied answers and false positives. Report coverage limits; fixture success does not prove general matching accuracy.
