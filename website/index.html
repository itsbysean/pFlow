Document code and processes with pFlow. 코드와 프로세스를 문서화합니다. コードとプロセスを文書化します。 为代码和流程生成文档。

Analyze a codebase or describe any process in natural language. pFlow creates Markdown documentation, graph JSON, and a standalone interactive HTML Viewer. 코드 저장소를 분석하거나 어떤 프로세스든 자연어로 설명하면 Markdown 문서, 그래프 JSON, 독립 실행형 HTML Viewer를 생성합니다. コードベースを分析するか、任意のプロセスを自然言語で説明すると、Markdown ドキュメント、グラフ JSON、スタンドアロンのインタラクティブ HTML Viewer を生成します。 分析代码库，或用自然语言描述任意流程，即可生成 Markdown 文档、图 JSON 和独立的交互式 HTML Viewer。

Capabilities기능機能功能

What pFlow does pFlow로 할 수 있는 일 pFlow でできること pFlow 能做什么

Trace code execution from a repository, or describe any other process in natural language. 저장소에서는 코드 실행 흐름을 추적하고, 그 밖의 프로세스는 자연어로 설명해 문서화합니다. リポジトリからコードの実行フローを追跡し、それ以外のプロセスは自然言語で説明して文書化します。 从代码仓库追踪代码执行流程，其他流程则用自然语言描述后生成文档。

01

Code architecture코드 아키텍처コードアーキテクチャ代码架构

Trace confirmed entry points through calls, decisions, external boundaries, and asynchronous relationships.확인된 진입점부터 호출, 분기, 외부 경계, 비동기 관계까지 추적합니다.確認したエントリーポイントから、呼び出し、分岐、外部境界、非同期の関係までを追跡します。从已确认的入口点出发，追踪调用、分支、外部边界和异步关系。

02

Process documentation프로세스 문서화プロセスの文書化流程文档化

Describe the steps, conditions, and outcomes. pFlow uses those facts and asks about gaps that affect the flow.단계, 조건, 결과를 설명합니다. pFlow는 제공한 내용을 바탕으로 정리하고 흐름에 영향을 주는 누락을 묻습니다.手順、条件、結果を説明します。pFlow は提供された内容をもとに整理し、フローに影響する不足点を質問します。描述步骤、条件和结果。pFlow 基于提供的内容进行整理，并就影响流程的缺失信息提问。

03

Explore the ViewerViewer에서 흐름 탐색Viewer でフローを探索在 Viewer 中浏览流程

Select nodes and branches, and open linked detail flows.노드와 분기를 선택하고 연결된 상세 Flow를 엽니다.ノードと分岐を選択し、リンクされた詳細 Flow を開きます。选择节点和分支，打开关联的详细 Flow。

04

Link diagrams and documents다이어그램과 문서 연결ダイアグラムとドキュメントの連携图表与文档联动

Select a diagram item to open its Markdown section. Search the documentation included in the Viewer.다이어그램 항목을 선택해 관련 Markdown 절을 엽니다. Viewer에 포함된 문서를 검색할 수 있습니다.ダイアグラムの項目を選択すると、対応する Markdown のセクションが開きます。Viewer に含まれるドキュメントを検索できます。选择图表中的项目即可打开对应的 Markdown 章节。可以搜索 Viewer 中包含的文档。

05

Review evidence근거 확인根拠の確認查看依据

Review source snippets or statements captured from a process description when available.저장소의 소스 발췌나 프로세스 설명에서 기록한 내용을 확인할 수 있습니다.リポジトリのソース抜粋や、プロセスの説明から記録した内容を確認できます。可以查看代码仓库的源码摘录，或从流程描述中记录的内容。

Standalone HTML Viewer독립 실행형 HTML Viewerスタンドアロン HTML Viewer独立 HTML Viewer

    Clarify missing details누락된 내용 확인不足している情報の確認确认缺失信息

It does not infer unstated rules.시작점, 순서, 분기, 결과가 불분명하고 도식에 영향을 주면 pFlow가 질문합니다. 설명에 없는 규칙은 임의로 채우지 않습니다.開始点、順序、分岐、結果が不明で図に影響する場合は、pFlow が質問します。説明にないルールは推測しません。当起点、顺序、分支或结果不明确且会影响图表时，pFlow 会提问。它不会推断描述中未说明的规则。
