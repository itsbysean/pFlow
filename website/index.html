Capabilities기능

What pFlow does pFlow로 할 수 있는 일

Trace code execution from a repository, or describe any other process in natural language. 저장소에서는 코드 실행 흐름을 추적하고, 그 밖의 프로세스는 자연어로 설명해 문서화합니다.

01

Code architecture코드 아키텍처

Trace confirmed entry points through calls, decisions, external boundaries, and asynchronous relationships.확인된 진입점부터 호출, 분기, 외부 경계, 비동기 관계까지 추적합니다.

02

Process documentation프로세스 문서화

Describe the steps, conditions, and outcomes. pFlow uses those facts and asks about gaps that affect the flow.단계, 조건, 결과를 설명합니다. pFlow는 제공한 내용을 바탕으로 정리하고 흐름에 영향을 주는 누락을 묻습니다.

03

Explore the ViewerViewer에서 흐름 탐색

Select nodes and branches, and open linked detail flows.노드와 분기를 선택하고 연결된 상세 Flow를 엽니다.

04

Link diagrams and documents다이어그램과 문서 연결

Select a diagram item to open its Markdown section. Search the documentation included in the Viewer.다이어그램 항목을 선택해 관련 Markdown 절을 엽니다. Viewer에 포함된 문서를 검색할 수 있습니다.

05

Review evidence근거 확인

Review source snippets or statements captured from a process description when available.저장소의 소스 발췌나 프로세스 설명에서 기록한 내용을 확인할 수 있습니다.

06

Standalone HTML Viewer독립 실행형 HTML Viewer

Open the generated HTML in a browser without a server. Viewer assets are included in the file.생성된 HTML 파일은 서버 없이 브라우저에서 열 수 있습니다. Viewer 리소스가 파일에 포함됩니다.

Installation and usage설치 및 사용 방법

Installation and usage설치 및 사용 방법

Install the Skill in a coding agent that supports Skills. Then describe the codebase or process to document.Skills를 지원하는 코딩 에이전트에 Skill을 설치한 뒤, 분석할 코드 저장소나 문서화할 프로세스를 설명합니다.

  1. 01

    Install the Skill folderSkill 폴더 설치

    Download pflow.zip from GitHub Releases. Extract it and copy the pflow/ folder to the Skills folder used by your agent. Keep SKILL.md, references/, and scripts/pflow.mjs together.GitHub Releases에서 pflow.zip을 다운로드하고 압축을 풉니다. pflow/ 폴더를 에이전트가 사용하는 Skills 폴더에 복사하고 SKILL.md, references/, scripts/pflow.mjs를 함께 둡니다.

    The Skills path varies by agent. Check its documentation. The ZIP becomes available after the first release is published.Skills 경로는 에이전트마다 다릅니다. 에이전트 문서에서 확인합니다. ZIP은 첫 릴리즈가 게시된 후 다운로드할 수 있습니다.

  2. 02

    Node.js requirementNode.js 요구 사항

    pFlow requires Node.js 24 or later. It does not need an npm install or a web server at runtime.pFlow를 실행하려면 Node.js 24 이상이 필요합니다. 실행 시 npm 설치나 웹 서버는 필요하지 않습니다.

    node /path/to/pflow/scripts/pflow.mjs --help

    Replace the path with the install location. This checks the packaged CLI; your agent invokes the Skill through its own Skills mechanism.경로는 설치 위치에 맞게 바꿉니다. 이 명령은 패키지 CLI를 확인하고, 에이전트는 자체 Skills 방식으로 Skill을 실행합니다.

  3. 03

    Choose what to document문서화 대상 지정

    For code, name the repository root and the entry point or area to trace. For another process, describe its steps, conditions, and outcomes.코드 분석에는 저장소 경로와 추적할 진입점 또는 범위를 지정합니다. 다른 프로세스는 단계, 조건, 결과를 설명합니다.

  4. 04

    Clarify missing details누락된 내용 확인

    pFlow asks when a missing start point, order, branch, or outcome would change the diagram. It does not infer unstated rules.시작점, 순서, 분기, 결과가 불분명하고 도식에 영향을 주면 pFlow가 질문합니다. 설명에 없는 규칙은 임의로 채우지 않습니다.

  5. 05

    Review the output결과 검토

    Review the Markdown and graph JSON. Confirm that cited evidence supports each relationship.Markdown 문서와 그래프 JSON을 검토하고, 인용한 근거가 각 관계를 뒷받침하는지 확인합니다.

  6. 06

    Open the HTML ViewerHTML Viewer 열기

    Open the HTML path reported by pFlow. Select flows or nodes, follow document links, search, and change the Viewer theme.pFlow가 안내한 HTML 파일을 브라우저에서 엽니다. Flow와 노드를 선택하고, 문서 링크와 검색을 이용하고, Viewer 테마를 바꿉니다.

Updating existing docs기존 문서 업데이트

Repository docs can be updated by scope through pFlow's impact, regeneration, and rebuild workflows. Prompt-based process docs support full generation only. pFlow asks before replacing content when ownership is unclear.저장소 기반 문서는 범위를 지정해 영향 분석, 재생성, 재빌드 흐름으로 업데이트할 수 있습니다. 프롬프트 기반 프로세스 문서는 전체 생성만 지원합니다. 기존 내용의 소유 범위가 불분명하면 pFlow가 교체 전에 확인합니다.
