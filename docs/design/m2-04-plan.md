# M2-04 — Selection, inspector, and documents

Research: `main` is clean at `40cee5b`. M1 supplies Node/Edge labels, kinds, evidence, optional external metadata, detail references, and Markdown links. It has no description field. M2-03 currently expands a node on click/Enter; the inspector and lower panels still use curated preview content. This interaction change is in scope and needs no schema change.

1. Separate selection and expansion. Give node bodies and edges keyboard-accessible selection controls; keep an explicit sibling detail button on owned expandable nodes. Update selection styling in place so selection cannot refit or pan the SVG. Preserve drag discrimination and recursive-detail notices.
2. Keep one small selection value (`type`, `id`) in the Viewer. Resolve it against the current Flow, its verified boundary stubs, and the original artifact. Clear selection on navigation and restore the new Flow's documentation. Keep entry/detail history unchanged.
3. Replace preview metadata with actual Node/Edge fields, evidence, endpoints, conditions, related calls, external metadata, and detail links. Hide irrelevant/empty sections. Present unresolved/unknown semantics explicitly without inventing facts or descriptions.
4. Embed exact copies of the sample Markdown bundles as offline fixture assets. Render the M1-03 subset with native DOM APIs: headings, literal entity sections, paragraphs, lists, tables, inline code, and links. Do not interpret raw HTML. Resolve bundle-relative document links and literal IDs; report absent/ambiguous sections rather than generating heading slugs. Source citations resolve to M1 SourceReferences, never network/local-file fetches.
5. Populate documentation from the active Flow and selected element's links, with an explicit owning-Flow fallback when an element has no documentation. Highlight and scroll within the document panel. Source buttons open accurate reference metadata with an unavailable-text state. Remove curated source excerpts; M4 embedding/extraction is deferred.
6. Extend pure and real-browser tests for inspector correctness, selection/expansion separation, keyboard access, Markdown resolution, source references, external metadata, stale selection, and viewport preservation. Retain navigation, cycle, responsive, offline, and single-file checks. Review the final UI and commit on `main`. Stop before M3.

Limits: this is an M1-03 Markdown renderer, not a full CommonMark engine. No source extraction, general artifact loader, full-text search, parallel graph model, or state-management package will be added.
